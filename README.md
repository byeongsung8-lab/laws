# 해양경찰 법령정보센터 (Korea Coast Guard Law Information Center)

해양경찰 관련 법률, 대통령령, 부령(법령) 및 훈령, 예규, 고시(행정규칙)를 로컬 PC에서 안전하고 편리하게 관리·검색·열람할 수 있는 독립형 로컬 웹 애플리케이션입니다.

---

## 📌 주요 특징
1. **국가법령정보센터 표준 레이아웃 적용**
   - 국가법령정보센터 메인 포털 형태의 직관적인 검색 및 메뉴 인터페이스 (첨부3 스타일)
   - 조문 트리 네비게이션과 법령 본문이 연동된 2분할 뷰어 화면 (첨부2 스타일)
2. **지정 컬러 시스템 적용**
   - 자연스럽고 신뢰감을 주는 고유 컬러 팔레트 적용 (`#3D5127` Deep Forest, `#A6BA35` Olive Lime, `#EBB839` Warm Gold, `#D36D43` Terracotta, `#F6F7F2` Ivory White)
3. **완전한 로컬 PC 독립 운영**
   - 외부 인터넷 망이 제한된 환경에서도 로컬 저장소와 가벼운 파일 기반 데이터베이스를 활용하여 원활히 구동
   - 원클릭 실행 스크립트(`start.bat`) 제공
4. **강력한 통합 검색 및 관리자 수동 업로드**
   - 법령명, 조문 본문, 소관부서 다차원 키워드 검색
   - 관리자 화면을 통한 법령/행정규칙 파일 및 메타데이터 수동 업로드/관리

## 🚀 빠른 시작 (Quick Start)
1. 의존성 설치:
   ```bash
   npm install
   ```
2. 로컬 서버 실행:
   ```bash
   npm start
   ```
   *(또는 `start.bat` 파일을 더블 클릭하여 실행할 수 있습니다.)*
3. 브라우저에서 `http://localhost:3000` 접속
